# 项目模型权重

本目录直接保存已审核快照中的1511个模型/检查点文件，总计364.01 MiB，包括PPO、MAPPO、门控/收益预测模型、SafeStep DQN及各训练阶段的检查点。没有按成绩挑选或删除较差的模型。

原相对路径保留在目录结构中，逐文件来源与SHA-256见[MODEL_INDEX.json](MODEL_INDEX.json)。`outputs/`对应研究工作区原来的输出目录；`tmp/`包含当时保留的最小运行检查权重。

这些是项目内保存的训练权重，不包含研究目录之外由Ollama管理的Qwen基础模型。加载模型需要对应版本的代码、网络结构和依赖；代码在[workspace](../workspace/)中。数据与训练过程的完整记录另保存在完整工作区分卷中。
