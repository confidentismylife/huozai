# 完整回合反事实护栏开发方案

日期：2026-09-30。本文件在该开发实验采集开始前保存。属于开发试验，不是第三轮正式最终评估的预注册。

问题：补齐控制器可记录的时间、执行器状态和传感历史，并用多个完整回合的模拟未来监督，能否改进条件动作筛选？本次同时改教师与类别，不能把新结果与旧护栏92.15%的召回率直接当作同一任务的提升。输入贡献通过相同新标签的有/无历史对照检验。

## 固定设计

- 场景种子20261301，新生成36个开发场景，六种冲突各六个，再添加北/南镜像。原36场景按每类ID排序：前四个训练、第五个校准、第六个开发审计。镜像与原场景同组。场景参数和分组先写入机器清单，不根据结果调整。
- 每场景两条轨迹：一条反应规则、一条随机动作；使用不同人群种子。每个类别、划分均覆盖两种轨迹，避免轨迹策略与冲突或划分混淆。
- 主开发条件使用既有校准Logit行为模型、无传感噪声。尚不能声称跨行为、跨噪声合格。
- 在可达的第0、8、16、24、40、64、96步采样。提前结束的回合不人为延长；报告实际晚期覆盖。
- 每个状态、每个九动作，三组未来随机数 × 两种继续计划，共54次完整回合模拟。继续计划共用相同方向决策，一种分级放行、一种全容量放行，等待均保留；两者差异仅在非等待的放行容量。
- 同一模拟未来保留已抽取的人群属性，只重抽未来路线选择和未来传感随机流。不同首动作可能改变随机数消耗顺序；不是逐人逐时刻的共同外生噪声配对。
- 每次模拟继续到终止或120步上限。仍保留原相对安全/危险的数值容差；六次教师全判安全才为安全，全判危险才为危险，其余为不确定。不强行指定一个安全赢家。模拟上限结束仍不代表每个人疏散成功。

## 可观测输入与对照

49维：原34维 + 时钟1 + 剩余标志保持时间1 + 当前执行标志反馈3 + 五区域烟气观测累计5 + 烟气观测变化5。

保持时间由控制器收到的实际标志反馈自行计数。烟气历史只累积已收到的传感读数，以前一时刻读数作矩形积分；有延迟时也只使用延迟观测。历史烟气量不是每个人真实FED。个体FED、属性、真实未来只供教师模拟，不能作为学生输入。

训练两个三分类护栏：

1. 有历史：使用全部49维可观测字段。
2. 无历史：新增15维全部置零，网络结构、参数数目、训练样本、随机初始化种子、预算均相同。

两者均将原建议五通道置零，避免建议来源影响护栏。每组训练三个随机初始化成员，各200轮；动作共享编码头，类别损失使用训练集类别频率的倒数权重。三成员只是分类器集成，不能称为三个PPO训练种子，也不独立于同一训练数据。

## 运行与开发评价

- 显式输出相对危险、安全、不确定三类分数；分数未经危险概率校准。
- 预测不确定分数≥0.5时弃权，允许该动作；其余按危险分数阈值筛选。保证只适用于“预测不确定”，不保证所有真实不确定动作通过。
- 所有动作被筛掉时，保留最低危险分数的动作，并保留并列。报告回退后的指标及回退率；回退无安全保证。
- 阈值在校准部分的0.05–0.95、181点上选择。先找整体达标阈值；不存在时按固定门槛违反量选择开发诊断点。不得根据审计部分调整阈值或模型。
- 审计整体及各冲突：危险拦截率≥95%，安全误筛率≤10%，最终首选动作危险率≤5%，有效掩码镜像一致性≥95%。缺少危险/安全样本的类别记为无法判断，不算通过。
- 同时报告安全/危险/不确定的样本数、已知标签覆盖、弃权、真实不确定动作被拒绝比例、首选动作不确定率，以及三分类混淆矩阵，防止通过扩大不确定标签掩盖失败。
- 独立场景家庭是重复单位；同场景多个状态、动作、镜像及模拟未来有相关性。开发审计只有六个原场景家庭，不据此作稳定的统计显著性结论。

无论开发指标是否通过，本次 `freeze_allowed=false`。正式冻结仍需另行固定独立资格验证设计、足够场景覆盖以及行为/噪声检验。第三轮PPO至少十种子及全新最终银行继续保留，当前不启动。

## 实施与复现

实现：`src/fire_evac/terminal_shield.py`；运行器：`scripts/build_terminal_shield.py`；输出：`outputs/terminal_shield_development_v1/`。

采集前写入场景、划分、预算、标签和源文件哈希。逐状态保存模拟结果，支持与清单一致的断点续跑；不覆盖旧开发和审计结果。

```powershell
python scripts/build_terminal_shield.py
python scripts/build_terminal_shield.py --resume
```

续跑必须使用相同参数和代码哈希。代码或设计修改时，使用新输出目录。本次不会调用新的LLM服务或付费API。
