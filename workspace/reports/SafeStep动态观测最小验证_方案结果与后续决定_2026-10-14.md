# SafeStep动态观测最小验证：方案、结果与后续决定

日期：2026-10-14。状态：先冻结后执行，144个回合及独立计算核查完成。本轮新增训练0次，LLM请求0次。

**本轮得到的证据支持：在会改变合适出口方向的合成场景中，更新危险观测并重新规划能够降低暴露；只有位置输入的既有DQN继续执行原来的固定左侧路线。简单规划已经能利用这些观测，因此下一阶段应先建立统一观测接口和较强规划基线，再决定是否需要学习算法。**

这是一次小型机制验证，使用设计的合成FER，没有新增原始FDS或真人数据。它解决了“当前任务能否区分固定路线和观测驱动调整”这个具体问题，不能当作SafeStep原论文数值复现或LLM有效性证据。

## 1. 为什么做这一轮

此前两个Room B主案例都适合走左路，无法检验控制器会不会根据危险改选方向。位置独热输入的DQN也无法直接接收新的烟气信息。此前合法动作修复解决了撞墙，未解决这个观察能力问题。

本轮在读取结果前冻结了场景、方法、指标、执行顺序和结束规则，没有根据成绩调整强度、追加训练或挑选种子。

## 2. 冻结的场景和信息条件

沿用24格小地图、单人、2米格长、0.3米/秒速度、四种相邻移动。主起点固定Room B。所有方法遵守相同几何合法动作约束；每步6.666…秒，上限128步。

场景组合如下：

| 因素 | 水平 |
|---|---|
| 高危险区域 | 左侧走廊，中心横坐标7；右侧走廊，中心横坐标17 |
| 危险出现时间 | 出发时已经出现；出发两步后才出现，即13.33秒后 |
| 危险峰值FER | 0.004、0.012 FED/秒，背景0.00005 FED/秒 |
| 出发时刻/旧模型组 | 起火后220秒、565秒，各匹配该组原DQN权重 |

危险按空间高斯分布、宽度0.9格构造，出现后保持。每个控制区间内FER固定，出口FER为0。它是便于检验决策机制的信号，不代表烟气物理传播。

共16个具体场景，实质是**8种相对危险模式在两组绝对时刻/旧模型下重复**。两组时间平移不提供独立火灾重复；左右场景、两档强度及旧DQN种子也不作为独立真人样本。全轮只报告描述性结果，不计算显著性或真实火情可靠性。

延迟场景中，左右危险版本在前两个控制步的全地图FER完全相同。直到第三次决策才出现可以区分方向的新观测。在线方法不能提前知道随后在哪一侧出现危险。

## 3. 实际比较的方法

| 方法 | 如何行动 | 实际使用的信息 |
|---|---|---|
| 固定左路 | 选择到左出口的最短合法路径 | 地图、位置 |
| 固定右路 | 选择到右出口的最短合法路径 | 地图、位置 |
| 最近出口 | 选择步数最少的出口 | 地图、位置；本地图上与固定右路相同 |
| 出发时规划一次 | 按出发时危险分布计算路线，之后沿用 | 地图、出发时完整且无噪声的FER观测 |
| 每步观测并重规划 | 每步按当前危险分布重算，执行其中一步 | 地图、当前完整且无噪声的FER观测；没有未来预报 |
| 既有DQN，种子41/42/43 | 保存权重与几何合法动作检查 | 位置独热输入；旧合成火情的训练先验 |
| 全未来规划参考 | 根据全部未来FER求有限时域最低代价 | 额外拥有未来信息，仅作参考下界 |

9种方法/模型设置，每种16回合，共144回合。没有新优化器或模型训练。

**这不是所有方法的同信息算法排名。** 既有DQN没有危险观测输入，且旧训练分布不同；其成绩只诊断冻结模型的局限，不能推断有危险输入的新DQN也会失败。全未来参考有额外信息。较直接的机制对照是两种采用相同规划算法、不同更新方式的规划器；更新版本同时增加了新观测与重规划次数，本轮没有单独分离这两个因素。

## 4. 指标如何定义

首先检查到达出口、撞墙和超时，再比较个人FED、疏散时长及预先定义的工程代价：

`J = 个人FED + 0.00125 × 移动步数`

系数固定来自既有奖励中普通移动与低剂量暴露项的比例，但**J是本轮明确提出的工程指标**，不等于原论文带分级毒性效用、回访惩罚和折扣的完整目标。原论文式折扣奖励仍逐步记录，二者没有混为一谈。失败回合没有有限的J分数。

未来参考按相同J和合法移动求解，作为已知完整未来场时的代价下界。执行时每步只使用当前FER的规划器，则假定当前危险保持来计算暂定路线，并没有调用未来参考。

预先冻结的机制验收要求是：立即危险场景随危险方向改变参考最优出口；在线方法在延迟危险揭示前动作一致；每步重规划在全部16例到达、不损失原单次规划的成功，并在四个延迟右侧危险的重复条件中降低J。若不满足，按失败记录结束，不改参数重跑。

## 5. 完整结果

各方法均为16/16到达，所有方法均无撞墙。故到达率在这批任务中不能区分路线质量。

| 方法 | 平均个人FED | 平均疏散时间（秒） | 平均J |
|---|---:|---:|---:|
| 固定左路 | 0.065160 | 100.00 | 0.083910 |
| 固定右路 | 0.062721 | 53.33 | 0.072721 |
| 最近出口 | 0.062721 | 53.33 | 0.072721 |
| 出发时规划一次 | 0.033278 | 65.00 | 0.045465 |
| **每步观测并重规划** | **0.004054** | **80.00** | **0.019054** |
| 既有DQN种子41 | 0.065160 | 100.00 | 0.083910 |
| 既有DQN种子42 | 0.065160 | 100.00 | 0.083910 |
| 既有DQN种子43 | 0.065160 | 100.00 | 0.083910 |
| 全未来规划参考 | 0.003835 | 76.67 | 0.018210 |

在这批等权设计条件中，每步观测重规划相对出发时规划一次：

- 平均个人FED降低**87.82%**。
- 平均J降低**58.09%**。
- 平均疏散时长增加**15秒**。

这些百分比仅概括本轮人为安排的左右危险、强度和出现时间组合；不是总体火灾效果估计，也不是原论文62%的复现或超越。

三个旧DQN的全部Room B轨迹均保持原来的15步左路，与固定左路逐动作相同。重复三个种子没有产生三种独立的适应行为。它们在左侧危险条件中仍然向左，只能表明当前冻结模型没有利用新危险信息。

所有立即危险配对中，全未来参考都随危险侧改变出口。每步重规划的改道发生在四个延迟右侧危险条件，各有一次必要的回访；这四例对应两档强度在两个绝对时刻组中的重复，不是四场独立火灾。

| 延迟右侧危险强度 | 单次规划J | 每步重规划J | J绝对下降 |
|---|---:|---:|---:|
| 低 | 0.072720 | 0.027021 | 0.045699 |
| 高 | 0.192826 | 0.027230 | 0.165596 |

两个绝对时刻组得到相同的上述结果，符合它们相对危险时序一致的定义。冻结的机制验收条件全部满足。

## 6. 一条具体轨迹：新观测如何改变决定

取220秒出发、右侧危险延迟出现、高强度这一例：

1. 出发时两边危险观测相同，右出口更近，两种在线规划器先进入R14，再向右到R15。
2. 233.33秒时，右侧危险首次进入可用观测。
3. 单次规划继续向右，最终53.33秒到右出口，FED为**0.182826**。
4. 重规划器从R15回到R14，转向左出口，最终113.33秒出去，FED为**0.005980**。

这次回头经过旧位置，属于必要的路线修正。回访数增加不能自动解释成控制失败，必须结合当前危险和最终结果判断。

拥有未来信息的参考从一开始就向左，100秒出去，FED约0.005000。它节省了在线规划器先向右再回头的两步，但在线方法在事件出现前没有信息区分未来左右两种情况，不能要求它无代价地预知未来。

## 8. 现在可以据此作出的决定

**本轮结束，采用每步观测的危险加权规划作为后续重要工程对照，继续暂停扩大训练。**

这次验证说明当前小地图已经能够区分固定路线与根据观测调整；也说明复杂学习之前存在一个有效、透明的简单方法。接下来若研究RL，应先让它与规划器使用明确登记的危险观测，再检验是否存在额外收益。观测候选至少包括位置、当前危险分布、时间与累计个人FED；若保留回访惩罚，还应考虑访问历史。但这些变量本身并不自动保证火情演化完全可观测或满足马尔可夫假设。

尚未检验局部传感、噪声、观测延迟、虚假预报、多火源、出口封闭、人群拥堵和新建筑。当前完整、精确的全图观测对规划器有利；所有轨迹最大FED约0.18548，仍未覆盖成功路线进入较高毒性档位的问题。因此不应把机制验收写成真实安全验证。

原论文精确复现仍依赖原始FDS/FER数据；老师“LLM模拟人、RL负责引导”的路线仍依赖行为与引导响应证据。这些缺口没有被本次单人规划实验填补。
