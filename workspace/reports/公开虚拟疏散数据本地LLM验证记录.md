# 公开虚拟疏散数据上的本地 LLM 路线选择预测试验

日期：2026 年 9 月 28 日。该试验检验本地语言模型能否从文字化的走廊属性预测公开实验中的人类路线选择。结果用于决定后续行为模型开发方向，不用于证明真实火场中的行为有效性。

## 数据和方法

数据来自 Snopková 等人的 [Figshare 数据集](https://doi.org/10.6084/m9.figshare.27705402.v1)及其[数据论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC11747338/)。原实验有 208 名参与者；每人观看虚拟建筑的可旋转画面，在 8 秒内选择 T 形路口的左或右走廊。任务编码记录了两侧走廊的宽度、长度和尽头是否有楼梯。数据为 CC BY 许可。

原始 `responses.csv` 共 4783 行。排除训练题或没有有效左右选择的 672 行，再排除含论文未明确解释的 `E` 长度代码的 66 行，剩余 208 人、4045 条有效选择、62 种可解码情境。按参与者固定随机划分为训练 125 人、验证 42 人、测试 41 人；同一人的试次不会跨组。最终测试集有 798 条选择。

模型为本地 Ollama `qwen3:4b`，摘要为 `359d7dd4bcda...`。每种情境只请求一次模型，使用固定中文提示、温度 0 和 JSON Schema，要求返回“类似参与者选择左侧的概率”。62 个情境的请求及原始回复均已缓存。提示只包含由任务编码解析出的走廊宽度、长度和楼梯信息，不包含测试参与者的选择。

对照有三个：训练数据的总体左侧选择频率；预先固定的短路径、无楼梯、宽走廊几何规则；训练参与者在相同任务上的选择频率。最后一个对照利用了训练集里相同任务的重复呈现，因此是本实验中重要的强基线。准确率按 `p_left >= 0.5` 判左侧；Brier score 越低越好。区间采用 5000 次参与者级配对 Bootstrap。

## 锁定测试结果

| 方法 | 准确率 | Brier score |
|---|---:|---:|
| 本地 Qwen3 4B | 0.6165 | 0.2378 |
| 训练集总体频率 | 0.4724 | 0.2511 |
| 固定几何规则 | 0.5201 | 0.3007 |
| 训练集同任务频率 | 0.8659 | 0.1158 |

LLM 相对总体频率基线的准确率差为 +0.1441，95% Bootstrap 区间为 [+0.0824, +0.2040]；相对固定几何规则为 +0.0965，区间为 [+0.0451, +0.1450]。相对训练集同任务频率，准确率差为 -0.2494，区间为 [-0.3074, -0.1866]，Brier 差为 +0.1220，区间为 [+0.0840, +0.1517]。这个强基线显著优于当前文字提示下的 LLM。

测试参与者选择左侧的比例为 0.4724，LLM 的平均左侧概率为 0.3861；模型只在约 21.9% 的试次预测左侧，显示当前提示和模型存在明显的右侧偏向。62 个情境的概率只落在 0.30 至 0.60 之间，也限制了区分强烈偏好的能力。

## 可解释范围和下一步

参与者看到的是可旋转的视觉场景并受到 8 秒倒计时约束，而 LLM 看到的是文字属性；两者的信息形式和时间压力不同。公开数据没有实测烟气、火源、人群队列或动态指示牌效应。这是一个**虚拟建筑路线选择的文本条件预测试验**，不能验证当前火灾环境中的 `LLMSurrogateBehavior`，更不能直接宣称预测真实火灾行为。

当前最省成本的下一步是先保留本地模型和缓存接口，分析模型右侧偏向，再用不接触锁定测试标签的验证参与者比较少量提示版本。若要进入论文主实验，应获得带有烟气、标志和服从行为的独立人员数据，并以锁定人员与锁定场景重新评估。只有外部行为模型通过验证后，才适合作为 RL 训练人员模型的依据。

后续左右镜像消融和独立数据核查已记录于[镜像验证报告](左右镜像验证与独立数据核查.md)。其数值来自原 42 名验证参与者，不应与上面的锁定测试结果混为一轮确认性评估。

可复现入口：`scripts/run_local_route_validation.py`。逐题缓存、参与者划分、测试预测、指标和 Bootstrap 结果均位于 `outputs/local_llm_validation/`。
