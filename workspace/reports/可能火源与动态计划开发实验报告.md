# 可能火源与动态计划开发实验报告

日期：2026-09-30。采集前设计见《可能火源与动态计划开发方案.md》。阶段：开发参考规划，非第三轮最终评估。

**已实现预测可能出错的两火源世界，并运行等待、实时改道和时段分流的动态计划。参考规划比本轮简单实时规则好，但考虑两个火源没有带来整体额外改善；既有纯PPO明显优于这套参考计划库。当前不能用此计划库直接指导或限制PPO。**

本轮没有重新训练PPO或LLM，没有更换原护栏门槛，也没有宣称护栏通过。开发结果和事后PPO复核分开保存。

## 一、信息不足时如何模拟

复用上一轮36个原开发场景、每场景两个人群种子，重现249个采样状态。此次不加入镜像。每个状态从回合开始分别重建北火源和南火源两种假设，保留预测、地图和已执行控制指令，各自产生历史烟气暴露和人员状态。

这里修正了一个容易产生无效反事实的问题：不能在后期直接翻转真实火源，再继续沿用原火源下已累积的个体FED。所有候选世界的历史都从起点重放。

仅根据当前烟气读数与假设世界预期读数的误差判定相容，不使用真实火源标签来挑选非oracle方案。假设只有火源方向会预测错误，增长、起烟时间和地图参数正确，传感无噪声，误差容差为1e-6。

249状态中，90个仍支持两火源，159个烟气已辨识出一个火源，没有出现两个世界均不相容的状态。这是当前简化环境的结果，不能推断真实烟气观测也能精确确定火源。

人群重放使用模拟人群种子和个体属性，仍是离线特权参考；在线系统并不知道每个人的真实属性和FED。世界平均使用等权0.5只是开发假设，未经真实火源可靠性校准。

## 二、比较了哪些控制计划

固定十二个候选：实时分级放行、实时全放行、最多等待1/3/6步后实时控制、固定预测目标全放行，以及25%/50%/75%预测目标时段占比分别配50%/100%房间放行的六种分流计划。

等待会在烟气区分火源时提前结束。分流只在烟气无法区分时使用，之后转实时分级控制；封闭路线触发实时备用选择。分流指的是标志时段比例，不是直接指定每个人的路线，实际人群比例不保证相同。

每个起点选择一次整套计划，计划内部响应实时观测；没有在每一步重新模拟十二个计划。选择以失能、FED、剩余人数、拥堵依次排序，规划只采样三个随机未来，不是全局最优或概率风险上界。

在同一计划库上比较三种可观测参考：暂不可辨识时采信预测的单火源、两世界等权平均、相容世界最坏平均结果。另加入直接知道真实火源的oracle，仅作特权诊断。

各计划用三个规划未来选出；检验使用另外三个随机未来，不复用选计划的随机样本。各组共享起点和评估随机数初始状态；动作改变仍可能改变随机数消耗顺序。

主试验实际进行12,204个规划回合及3,966个不同的检验回合，共16,170次完整回合模拟。同一计划被多个组选到时复用完全相同的检验结果，形成6,723条组别记录，不能误报为6,723次不同模拟。

## 三、初始起点的主要开发结果

从第0步开始，每组36个场景×两个人群×三个检验未来，共216条结果。每个场景等权，重复单位是场景家庭，不是每个状态、动作或随机未来。全部使用旧开发场景，属于探索性描述。

| 控制方式 | 平均失能率 | 平均FED |
|---|---:|---:|
| 实时分级规则 | 10.23% | 0.412 |
| 实时全容量放行 | 10.24% | 0.401 |
| 最多等待3步后实时控制 | 11.22% | 0.478 |
| 50%标志时段分流、全放行 | 10.23% | 0.411 |
| 固定预测目标、全放行 | 11.82% | 0.415 |
| 单火源参考选计划 | 7.83% | 0.410 |
| 两世界等权参考 | 7.94% | 0.412 |
| 两世界最坏平均参考 | 7.94% | 0.412 |
| 真实火源oracle参考 | 7.64% | 0.404 |

相对于实时分级规则，两世界最坏平均参考失能减少2.30个百分点；场景家庭Bootstrap的探索性95%区间约为[-3.57,-1.16]个百分点。等待3步整体增加0.99个百分点。不能根据某些等待场景改善而把所有不确定情况都设成等待。

单火源参考本身能够依据新烟气纠正预测，并不是全程盲信预测。单火源选计划7.83%好于简单实时规则，说明额外计划搜索在这个小库中有作用，但不能据此证明考虑两个火源有额外价值。

### 两火源处理的收益与代价

36个场景中11个初始预测错误，25个正确；这是实验设计/评价标签，不提供给非oracle选择器。

| 初始预测情况 | 实时分级规则 | 单火源选计划 | 两世界等权 | 两世界最坏平均 |
|---|---:|---:|---:|---:|
| 错误，11场景 | 8.40% | 6.83% | 6.58% | 6.32% |
| 正确，25场景 | 11.04% | 8.26% | 8.53% | 8.65% |

两世界最坏平均对预测错误子集比单火源减少0.51个百分点，但对正确子集增加0.39个百分点；整体增加0.11个百分点。补充的场景家庭Bootstrap区间为：整体[-0.29,+0.63]；预测错误[-1.27,0.00]；正确[-0.03,+1.03]个百分点，均不能作为稳定额外收益的证明。子集只有11/25个场景，全部为探索性。

仅有均值为0.5的世界权重与最坏世界规则并不足以决定何时信任预测。需要在开发训练部分校准预测可靠性和观测误差，并在未见场景验证这种校准。

### 计划选择频率

在249个起点上，两世界最坏平均选择：实时控制166次、等待19次、固定预测目标18次、分流46次。说明该参考已经能够在不同计划间选择，而不是统一等待、统一放行或统一反向。

这些选择频率本身不是有效性的证据。烟气已辨识的159状态上，四种计划库参考的平均失能率相同，约7.70%；此时没有火源分歧，但计划库仍存在明显局限。

## 四、事后复核：已有PPO是否更强

因为计划库仅优于较简单规则，追加事后参照，防止用较弱教师强制指导已较强的控制器。使用之前五个纯PPO模型601–605，参数保持原样，在与本轮初始参考相同的36场景、两个人群及三个检验随机未来上运行，共1,080个回合。

| 冻结纯PPO模型 | 失能率 |
|---|---:|
| 601 | 1.93% |
| 602 | 2.86% |
| 603 | 4.89% |
| 604 | 3.44% |
| 605 | 3.42% |
| 五模型平均 | 3.31% |

五个模型均低于两世界参考的7.94%；五模型平均低4.63个百分点，平均FED约0.342。模型原训练步数均为50,176，本次没有再训练。

这是事后能力参照，不是新的公平训练消融：既有PPO在另一场景银行训练、使用34维观测；规划参考使用49维且有特权人群重放。其用途是检查教师是否值得采用，不能证明某个新增特征、LLM或世界建模的因果作用。

即使直接知道真实火源，本十二计划库的oracle仍有7.64%失能。这说明在本试验条件下，单纯纠正火源未知不足以解决计划库与已有PPO之间的差距。当前不应把库内“最优动作/计划”当作环境最优，也不应直接作为强制动作屏蔽或主要监督目标。

## 五、本轮能支持的结论

1. 可能火源的世界重建和基于烟气的相容性判断已经可运行；历史状态得到一致重建，未沿用不相容世界的旧暴露记录。
2. 等待、实时改道、时段分流的闭环计划已有完整模拟比较，评估随机未来与规划分离。
3. 两世界处理在预测错误子集表现较好，但整体没有超过单火源参考；收益与保守代价都必须报告。
4. 本次简单计划库弱于已有PPO，不能作为可靠监督教师。这是当前更直接的限制，需要先补强教师，而不是只继续调分类阈值。
5. 本轮没有建立任何LLM+PPO提升，也没有让学习护栏达到资格门槛。原95%/10%/5%门槛不变，正式十训练种子和全新最终银行仍未启动。

下一阶段应把五个既有PPO作为闭环候选加入参考库，而不是只在几个手写规则间搜索；同时保留所有五个固定模型和规则候选，不能看到结果后只挑表现最佳种子。先检查扩展教师能否在新的规划/检验随机流上达到或超过这些强基线，再决定是否蒸馏风险或计划建议。

此后若风险信息作为PPO软建议，应与相同信息和预算的纯PPO、规则、随机及真实LLM建议作对照。世界评分只作为未验证的建议，不能在当前失败条件下覆盖PPO作为所谓安全护栏。
