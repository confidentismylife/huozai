# “当前是否值得再次覆盖PPO”：执行结果与判断

日期：2026年10月7日。对应[已冻结的完整确认实验报告](C:/Users/摩天轮大盗/Documents/ChatGPT/LLM探索/reports/再次覆盖PPO门控确认实验报告_2026-10-07.md)。本文件补充结果解释，保留所有旧结果与冻结方案。

## 1. 先说结论

这一步已经执行完。我们验证了：限制同一建议再次覆盖，可以减少这些开发情景中的一部分损失；但当前门控没有达到“区分有害与有益再次覆盖”的目标。

即时模式共有24次再次覆盖机会，两种门控都拦住13次有害建议，同时拒绝全部5次有益建议，另外6次效果微小。这说明它们在这批状态上实际做的是全部拒绝再次覆盖。拦住有害100%、误拒有益100%，不能解读成门控判断能力强。

实测延迟模式没有再次覆盖机会，不能用它验证再次覆盖识别能力。该模式的“仅首次覆盖”与“持续提示”在全部200个配对回合中，完整动作链及轨迹完全一致。

## 2. 实际做了哪些工作

- 冻结两种门控后，使用20批全新人口运行2,080个完整回合：五种PPO控制各400回合，同信息规则单独80回合。
- 从持续提示、首次门控、证据门控的真实轨迹保存248个建议覆盖机会，包含接受与拒绝状态，运行2,480条完整终点反事实。
- 记录102,632个实际控制步；重算98,706次公开特征与门控判断。248个实际续跑的11,843个后续控制步精确重现。
- 用独立标准库脚本重算18组完整回合配对效果、248组事件效果、64组门控混淆统计，核对287个文件哈希。
- 17项测试通过。请求动作与实际动作不一致、进入不可用走廊、放行超限、非法方向均为0。

模型来源为真实Qwen3 14B缓存。没有新增LLM请求、没有训练PPO、没有调整Ollama，48个保留最终情景继续封存。

五个情景共用同一五区域图结构：房间A、房间B、路口、北走廊、南走廊。参数情景、不同人口、不同人群行为、五套权重及随机未来不能当成独立建筑样本。

## 3. 有害拦截与有益误拒，必须一起看

主要评价在“保留档位、持续提示”的同一批状态上进行影子决策，避免把门控各自改变后的不同轨迹混成同状态比较。每个建议与PPO动作分别强制一步，随后统一使用无建议PPO直至终止。失能差优先于FED差，冻结描述阈值均为±0.001。

|时序及机会范围|门控|有害拦住/有害总数|有益误拒/有益总数|接受的有害|接受的有益|
|---|---|---:|---:|---:|---:|
|即时，首次40次|仅首次覆盖|0 / 6|0 / 13|6|13|
|即时，首次40次|公开状态证据门控|6 / 6|11 / 13|0|2|
|即时，再次24次|仅首次覆盖|13 / 13|5 / 5|0|0|
|即时，再次24次|公开状态证据门控|13 / 13|5 / 5|0|0|
|延迟，首次24次|仅首次覆盖|0 / 6|0 / 10|6|10|
|延迟，首次24次|公开状态证据门控|6 / 6|8 / 10|0|2|

首次覆盖也不是天然有益：不判断收益、只允许首次的基线，在即时和延迟模式都接受了6次局部有害建议。

公开状态门控在即时模式全部64次机会中拦住19次有害建议，但误拒16/18次有益建议，误拒率88.9%；延迟模式拦住6次有害建议，误拒8/10次有益建议，误拒率80%。中性拒绝没有被计成“拦住有害”。

这些是同状态终点反事实标签，不是被拒绝建议的实际执行后果。概率人群每个状态使用实际未来与三个冻结未来，标签取配对均差；有限未来采样不是校准后的损害概率。原实际未来的续跑必须精确复现父回合，全部通过。

恢复父策略继续使用建议的终点反事实也单独保留，检查一次选择与后续控制的交互。本轮24个再次覆盖状态的局部和恢复父策略分类一致，不能把不同事件收益累加成全程效果。

## 4. 完整回合是否改善

每行200个配对比较，候选减同权重无建议PPO。FED负差为较低烟气暴露，失能负差为较少失能。

|时序|控制方式|平均FED差|平均失能差（百分点）|
|---|---|---:|---:|
|即时|保留档位、持续提示|+0.000353|-0.0208|
|即时|仅首次覆盖|-0.000372|-0.0729|
|即时|公开状态证据门控|-0.000217|-0.0208|
|实测延迟|保留档位、持续提示|+0.000100|-0.0708|
|实测延迟|仅首次覆盖|+0.000100|-0.0708|
|实测延迟|公开状态证据门控|-0.000217|-0.0208|

即时模式中，“仅首次覆盖”相对持续提示的平均FED减少0.000725，失能率减少0.0521个百分点。它同时改善了这两个均值，但仍有5个完整配对比持续提示更差，对应拒绝有益再次覆盖的代价。

证据门控的即时均值相对持续提示降低FED，平均失能基本不变；延迟模式相对持续提示虽然FED降低0.000317，但失能反而增加0.0500个百分点。不能只选择暴露这一项宣布更好。

证据门控每种时序在200回合中只执行2次覆盖，其余198回合与无建议PPO结果一致。两个有效病例都来自AULL0010、权重605、Rule人群、人口1497100700和1497100702，每个病例比无建议PPO少5人失能。两种时序复用这两批人口，不是四个独立成功病例。它没有展示在概率人群上的有效覆盖，也没有展示其他权重上的收益。

“仅首次覆盖”的即时失能改善也全部来自AULL0010、权重605；其他情景保留FED正负差异。总体均值、场景分解、行为分解和权重分解全部保存。

这里的终止时间表示模拟回合结束，可能因人员失能而提前；全员成功疏散时间只在全部人员成功离开时记录。未将提前失能终止当成疏散更快。

## 5. 为什么证据门控几乎都拒绝

这次没有拟合复杂收益预测器。我们用旧44个状态做保守的公开特征查表：去掉重复时序副本后36个归档状态，形成19个状态格，仅2格满足“每个已知未来都有益、且没有失能增加”。未知格、混合结果及微小结果都保留PPO。

24次再次覆盖中，5次被拒绝的有益建议有4次落在已有但证据不一致的格，1次落在未知格。当前查表没有为任何再次覆盖给出接受支持。

人数按5人分格、烟气按0.005分格会损失信息。确认结果的只读诊断发现：

|再次覆盖状态的表示|公开状态类别数|同时含有有益与有害结果的类别数|落在这些冲突类别中的状态数|
|---|---:|---:|---:|
|当前门控的分格特征|11|2|10|
|保留原始当前观测与动作/机会记录|22|1|2|
|再保留完整公开控制历史|23|1|2|

更细的观测减少了分格造成的混合，但还有一组无法由这些已记录公开信息区分：

- AULL0019、权重604、第15秒，人口1497101301、CalibratedLogit人群，覆盖FED差+0.001213，归为有害。
- 同一情景、权重与时刻，人口1497101302、Rule人群，覆盖FED差-0.009772，归为有益。

这两例的34维公开观测及此前公开动作、放行上限与人数历史一致，背后的人群组成和行为模型不同。控制器没有读入人群模型编号或个体属性。

这只说明在当前记录中存在公开历史相同而收益反转的病例，不能证明所有合法公开信息都无法预测收益，也不能证明细分状态就能解决泛化。使用这些确认标签做了结果诊断，但没有重新拟合门控；这批人口后续应视为开发材料。

## 6. 本轮决定与下一步

本轮不采用新门控，也不扩大PPO训练。问题已经更具体：既要避免低容量出口上的有害重复转向，又不能把AULL0013、0019中的有益重复转向全部拒绝。

下一步先解决信息与预测目标问题：

1. 用现有缓存分开检查“分格损失”“旧证据不足”“相同公开历史下的人群差异”，不要先堆训练量。
2. 检查能合法提供的人群响应信息，例如两侧实际出流、拥堵消退速度、对指示牌的历史响应；若要增加观测，先明确现实中如何测得，不能读取模拟器隐藏个体参数作为在线输入。
3. 门控预测的是当前具体候选相对PPO的净收益，并表达不确定性。先在开发材料检验校准与收益反转，再冻结另一批确认人口/情景；现有标签不能同时充当训练和独立确认。
4. 继续同时报告有害拦截率、有益误拒率、实际覆盖次数及全程结果。单纯全部拒绝的门控保留为诊断基线，不称为智能收益判断。
