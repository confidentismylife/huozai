# LLM + 强化学习火灾疏散研究记录

本仓库保存项目对话中形成的**脱敏研究记录**，用于追踪研究问题、实验设计、关键结果、失败机制和后续决策。记录截至 **2026-10-22**。

本项目研究两个相关但必须区分的问题：

1. LLM能否根据真人疏散数据模拟出口选择与改道行为；
2. LLM提供的高层计划能否为PPO/MAPPO疏散控制带来超过数值状态、人工规则和置换计划的增量价值。

## 当前结论

- 已建立五分区、双出口、方向与分级放行联合控制的仿真闭环，并完成PPO、MAPPO、规则计划、LLM计划及多种门控对照。
- 当前DeepSeek计划通道会改变MAPPO的请求动作，但尚未证明**匹配当前状态的计划内容**优于同事件置换计划。
- 主要执行瓶颈是容量动作采用：方向采用率约为47.7%–54.6%，容量档位采用率约为30.2%–39.8%，方向与容量同时一致仅约10.1%–12.9%。
- 动作风险排序接口虽然32/32响应合法，但没有通过烟气、拥堵和趋势敏感性准入，且30/32次首选最低0.25放行档。
- 在Snopková真人出口选择任务上，本地Qwen3 4B准确率约61.65%，明显低于同任务真人频率基线约86.59%，不能据此认定LLM已能可靠模拟真人。
- SafeStep关键机制与若干公开数值已复现，但缺少原作者完整数据、权重与精确配置，不能声称完整复现原论文。
- 最终48个测试场景继续封存；本仓库中的结果属于开发证据，不是最终盲测或真实建筑部署证据。

## 研究原则

- 保留负结果，不为使LLM表现更好而事后改阈值、删场景或削弱基线。
- 比较方法时统一信息、动作空间、训练预算和评估场景。
- 区分独立训练后的系统差异、固定权重的计划内容差异和执行层采用率。
- 开发集用于诊断，最终集在方案冻结前不得查看。
- 仿真改善不直接等于真实建筑安全收益。
